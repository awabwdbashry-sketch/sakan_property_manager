## 📖 نبذة عن المشروع

**سَكَن | SAKAN Property Manager** هو نظام ويب لإدارة العقارات والوحدات السكنية وعقود الإيجار والمستأجرين والعمليات المالية من خلال لوحة تحكم عربية مصممة لتسهيل متابعة أعمال إدارة الأملاك.

يساعد النظام مالك العقار أو الموظفين المصرح لهم على تنظيم بيانات العقارات والوحدات، وإدارة عقود الإيجار، ومتابعة استحقاقات الإيجار والتحصيلات والمصروفات، بالإضافة إلى إدارة الصيانة والإشعارات والتقارير.

صُمم النظام بواجهة عربية تدعم اتجاه الكتابة من اليمين إلى اليسار **RTL**، مع قاعدة بيانات مركزية لحفظ سجلات النظام وتنظيم العلاقات بينها.

## 🎯 أهداف النظام

- 🏠 جمع بيانات العقارات والوحدات في مكان واحد.
- 📑 تنظيم عقود الإيجار ومتابعة مددها واستحقاقاتها.
- 💵 متابعة الإيجارات المستحقة والمدفوعة والمتأخرة.
- 🧾 توثيق التحصيلات المالية والإيصالات والمصروفات.
- 🔧 تنظيم طلبات الصيانة ومتابعة حالاتها.
- 🔔 تنبيه المسؤول إلى الالتزامات والمهام التي تحتاج إلى متابعة.
- 📊 تسهيل مراجعة البيانات واستخراج التقارير.
- 🔐 تنظيم صلاحيات المستخدمين وتوثيق العمليات المهمة.

## 💰 الإدارة المالية

يركز النظام على تنظيم السجلات المالية المرتبطة بالإيجارات والتحصيلات والمصروفات.

تشمل دورة العمل المالية:

1. 📑 تسجيل عقد الإيجار.
2. 📆 متابعة الاستحقاقات المرتبطة بالعقد.
3. 💳 تسجيل الدفعات الفعلية عند التحصيل.
4. 🧾 توثيق الإيصالات المرتبطة بالدفعات.
5. 💸 تسجيل المصروفات العقارية والتشغيلية.
6. 📊 مراجعة البيانات والتقارير المالية.

**مبدأ مهم:** إنشاء عقد الإيجار لا يعني تسجيل دفعة مالية تلقائيًا؛ يجب تسجيل التحصيل الفعلي بصورة مستقلة حتى تبقى السجلات المالية واضحة.

## 📲 التذكير عبر واتساب

يدعم تصميم سير العمل المطلوب متابعة الإيجارات المتأخرة وتجهيز رسائل تذكير للمستأجرين.

آلية العمل المقصودة:

1. 🔎 تحديد الاستحقاقات التي تجاوزت موعد السداد ولم تُسوَّ بالكامل.
2. 🔔 تنبيه المسؤول أو مالك العقار إلى وجود إيجار متأخر.
3. 📝 تجهيز رسالة تذكير مناسبة للمستأجر.
4. 👀 مراجعة الرسالة وبيانات المستأجر بواسطة المسؤول.
5. ✅ تأكيد المسؤول قبل فتح واتساب وإرسال الرسالة يدويًا.

**لا يتم إرسال رسائل واتساب تلقائيًا دون موافقة المسؤول.** فتح واتساب وتجهيز الرسالة لا يعني أن الرسالة أُرسلت بالفعل؛ يجب على المستخدم مراجعتها وإرسالها.

## 🗂️ هيكل الملفات

يوضح الهيكل التالي الملفات والمسارات الأساسية المعروفة في المشروع، وليس قائمة حصرية بجميع ملفاته:

```text
sakan_property_manager/
│
├── 📁 config/
│   ├── config.php
│   └── local.php
│
├── 📁 database/
│   ├── schema.sql
│   └── 📁 migrations/
│       ├── 002_reminders_whatsapp.sql
│       └── rollback الخاص بالترحيل
│
├── 📁 setup/
│   └── ملفات الإعداد الأولي للنظام
│
├── 📁 cron/
│   ├── run.php
│   └── backup.php
│
├── 📄 .htaccess
├── 📄 .gitignore
├── 📄 README.md
└── 📄 ملفات ومجلدات التطبيق الأخرى
```

**ملاحظات حول الملفات:**

- `config/config.php`: ملف إعدادات النظام الأساسي.
- `config/local.php`: إعدادات محلية، مثل اتصال قاعدة البيانات، إذا كان المشروع يعتمد عليه؛ لا ينبغي نشر بيانات الاتصال السرية.
- `database/schema.sql`: ملف إنشاء بنية قاعدة البيانات.
- `database/migrations/002_reminders_whatsapp.sql`: ملف ترحيل مرتبط بالتذكيرات عبر واتساب.
- `setup/`: ملفات الإعداد الأولي وإنشاء حساب المسؤول وفق آلية المشروع.
- `cron/run.php`: نقطة تشغيل المهام المجدولة.
- `cron/backup.php`: نقطة تشغيل النسخ الاحتياطي.
- `.htaccess`: إعدادات Apache والحماية المناسبة للمسارات.
- `.gitignore`: تحديد الملفات التي لا ينبغي تتبعها في Git.

## 🚀 خطوات التثبيت

### 1️⃣ تجهيز المشروع

ضع مجلد المشروع داخل مجلد `www` الخاص بـ WAMP. مثال:

```text
D:\wamp\www\sakan_property_manager
```

### 2️⃣ تشغيل الخدمات

شغّل خدمتي Apache وMySQL من لوحة تحكم WAMP، وتأكد من أن الخدمات تعمل بصورة صحيحة.

### 3️⃣ إنشاء قاعدة البيانات

افتح phpMyAdmin، وأنشئ قاعدة البيانات باسم:

```sql
CREATE DATABASE IF NOT EXISTS sakan_property_manager
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

### 4️⃣ استيراد المخطط

1. افتح قاعدة البيانات `sakan_property_manager`.
2. انتقل إلى تبويب **Import**.
3. اختر الملف `database/schema.sql`.
4. نفّذ الاستيراد وتأكد من عدم ظهور أخطاء.

إذا كانت نسخة المشروع تتطلب ترحيلات إضافية، فراجع ملفات `database/migrations/` وتعليمات المشروع قبل تشغيلها.

### 5️⃣ إعداد الاتصال

راجع إعدادات الاتصال بقاعدة البيانات في ملفات الإعداد. اضبط بيانات المضيف واسم قاعدة البيانات واسم المستخدم وكلمة المرور بما يناسب بيئتك المحلية.

لا تنشر كلمات المرور أو بيانات الاتصال الخاصة بخادم حقيقي في المستودع العام.

### 6️⃣ تشغيل صفحة الإعداد

افتح الرابط التالي في المتصفح:

`http://localhost/sakan_property_manager/setup/`

أكمل خطوات الإعداد الأولي، وأنشئ حساب المسؤول الأول وفق ما تعرضه صفحة الإعداد.

### 7️⃣ التحقق من التشغيل

بعد إكمال الإعداد:

- 🔑 سجّل الدخول بحساب المسؤول.
- 🏠 تحقق من فتح لوحة التحكم.
- 🗄️ تأكد من اتصال النظام بقاعدة البيانات.
- 🧾 اختبر العمليات المالية في بيئة آمنة قبل إدخال بيانات حقيقية.
- 🔔 راجع إعدادات التنبيهات والتذكيرات.
- 💾 اختبر النسخ الاحتياطي والاستعادة وفق تعليمات المشروع.

### 8️⃣ إعداد المهام المجدولة

يمكن إعداد مهام PHP المجدولة من خلال Windows Task Scheduler أو آلية جدولة مناسبة للخادم، إذا كانت مطلوبة في نسخة المشروع.

راجع ملفات المهام وإعداداتها قبل تشغيلها بصورة دورية، وتأكد من أن مسارات PHP والملفات وصلاحيات الكتابة صحيحة.

## 📖 Project Overview

**SAKAN Property Manager** is a web-based property management system designed to organize properties, residential units, tenants, rental contracts, rent installments, payment collections, expenses, and maintenance operations through a centralized dashboard.

The system helps property owners and authorized staff manage day-to-day operations, monitor rental obligations, document financial transactions, and follow up on maintenance requests.

Its interface is designed primarily in Arabic with right-to-left (**RTL**) layout support, backed by a relational database for managing application records.

## 🎯 Project Objectives

- 🏠 Centralize property and unit records.
- 📑 Organize rental contracts and their associated obligations.
- 💵 Monitor paid, outstanding, and overdue rent.
- 🧾 Record collections, receipts, and expenses.
- 🛠️ Track maintenance requests and their status.
- 🔔 Notify administrators about items requiring attention.
- 📊 Support reporting and data review.
- 🔐 Manage authorized users and maintain audit records.

## ✨ Key Features

### 🏢 Property and Unit Management
- Maintain property and building records.
- Organize units under their respective properties.
- Track unit information and status.
- Associate units with relevant rental records.

## 📲 WhatsApp Reminders

The intended overdue-rent workflow helps administrators identify late payments and prepare reminder messages for tenants.

The workflow is:

1. 🔎 Identify installments that are past due and not fully settled.
2. 🔔 Notify the property owner or administrator that rent requires follow-up.
3. 📝 Prepare a suitable reminder message.
4. 👀 Allow the administrator to review the message and tenant details.
5. ✅ Require administrator confirmation before opening WhatsApp and sending the message manually.

**WhatsApp messages are not sent automatically without administrator approval.** Preparing or opening a message does not mean it has been sent; the user must review and send it.
